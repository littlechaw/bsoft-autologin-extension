# BSOFT Wi-Fi 一键登录

这是一个仅在本机使用的 Chrome Manifest V3 扩展。它只可访问公司网关。点击扩展图标后，它会创建带有一次性任务标记的后台临时标签页；登录页加载后自行执行认证，成功页回报结果，成功或超时后关闭该标签页。

## 安装

1. 在 Chrome 打开 `chrome://extensions`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择此目录。
5. 在扩展菜单中将“BSOFT Wi-Fi 一键登录”固定到工具栏。

## 初始化配置

1. 将 `config.example.js` 复制为 `config.js`。
2. 将 `config.js` 中的 `authUrl` 替换为当前设备打开的 BSOFT 网关登录页地址。

`config.js` 已被 Git 忽略，请勿提交其中的设备网络标识或任何凭据。

## 使用

1. 连接公司 Wi-Fi。
2. 点击浏览器工具栏中的扩展图标，再点击“一键登录”。
3. 扩展会在后台完成认证，并在成功、失败或超时后自动关闭临时网关标签页。

## 修改凭据

工号和密码不写入文件。首次使用时在弹窗输入工号和密码并点击“一键登录”，扩展会将其保存至本地存储，后续自动回显并使用。若设备 IP、MAC 或网关页面标识变化导致认证失败，需用当前登录页地址替换 `config.js` 的 `authUrl`。

## 限制

- 对配置的公司网关，扩展会在临时登录标签页中自动忽略证书隐私警告，效果等同于手动点击“高级”后选择“继续前往”。仅应在确认该网关地址可信且由公司提供时使用。登录页若发生 HTTP/HTTPS 重定向也会继续注入登录脚本。
- 它依赖当前网关页面的 `#username`、`#password` 和 `#loginBtn` 控件。网关页面改版后可能需要同步更新脚本。
